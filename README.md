# 📊 Análisis de Datos con Python

¡Hola!  Este es mi repositorio del curso de **Análisis de Datos con Python**,
donde voy guardando todo lo que aprendo y desarrollo semana a semana: desde los
primeros pasos con Python hasta funciones más avanzadas para limpiar y analizar
datos.

##  ¿Qué vas a encontrar aquí?

| Carpeta / archivo | ¿Qué contiene? |
|---|---|
| `notebooks/` | Los notebooks de cada semana, con ejercicios y explicaciones |
| `data/raw/` | Los datos **originales**, tal como los recibí (sin tocar) |
| `data/processed/` | Los datos ya **limpios**, listos para analizar |
| `src/funciones.py` | Las funciones de Python que fui creando y reutilizando |
| `reports/figuras/` | Las gráficas y visualizaciones que voy generando |
| `requirements.txt` | Las librerías necesarias para correr todo esto |

##  ¿Cómo lo uso?

1. Clona este repositorio.
2. Instala las librerías necesarias:

   ```bash
   pip install -r requirements.txt
   ```
3. Abre los notebooks en `notebooks/` en el orden de las semanas y ¡listo!

##  Sobre este proyecto

Es un proyecto de aprendizaje: aquí se ve el proceso, desde el código más
simple de las primeras semanas hasta funciones más organizadas y
modularizadas más adelante.
